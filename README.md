# Decision Council

A five-agent Claude plugin that reviews any idea and returns a rated verdict. A Researcher, Believer, Skeptic, Investor and Judge debate startups, features, technical changes or life decisions.

## Install

In Claude Code:

```
/plugin marketplace add DavidDruker/decision-council-claude-plugin
/plugin install council@decision-council
```

Then try: "Run the council on my idea for …", or call one agent directly: "Have the skeptic tear apart …".
